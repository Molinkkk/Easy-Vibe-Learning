# Easy-Vibe-Learning

Datawhale Easy-Vibe 15-Day Learning Project — AI-Native Development, Vibe Coding, AI Agents and Practical Projects.

本仓库用于集中记录 Easy-Vibe 学习过程、实践代码、阶段性产出与项目总结。内容以实际课程任务和个人实践为准，逐步完善。

## 学习内容

- 课程笔记与知识整理
- 每日学习记录
- AI 辅助开发实践
- 阶段任务代码与演示材料
- 最终项目及复盘总结

## 使用方式

1. 按课程进度在对应的 Task 目录中整理任务说明、笔记和实践成果。
2. 每日记录放在 `docs/daily-records/`。
3. 项目运行方式、依赖和演示截图应写入对应 Task 的 README。
4. 暂未开始或尚未确认的任务内容先保留目录，不预设课程要求。

## 提交规范

建议使用清晰、简短的提交信息，例如：

- `docs: add learning notes`
- `feat: implement task 01 demo`
- `fix: resolve project issue`
- `refactor: improve project structure`

## 注意事项

- 不要提交 API Key、Token、密码、私钥或其他敏感信息。
- 不要提交未经授权的个人信息、课程资料或第三方受版权保护的完整内容。
- 实践项目应尽量提供可复现的运行步骤。
