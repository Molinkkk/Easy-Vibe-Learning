## 2. 本章学习目标

根据官方教程，本章主要学习：

1. **本地开发环境搭建：** 理解从网页版 AI 编程转向本地项目开发的工作方式。
2. **IDE 与 AI IDE：** 了解 IDE 在代码编辑、项目文件管理、运行和调试中的作用，以及 AI IDE 如何通过大语言模型和 Agent 辅助生成、理解、修改和测试代码。
3. **高效开发技巧：** 学会将需求具体化、分步骤推进、使用截图和报错辅助沟通，并通过运行验证与反复反馈改进结果。

## 3. 官方课程内容梳理

### 3.1 遇到问题，先问 AI

安装环境、执行命令或处理依赖报错时，可以先向 AI 描述目标和当前情况，让 AI 帮助检查、解释或提出操作方案。涉及安装、删除、覆盖文件及其他有影响的操作时，仍需检查命令和变更后再确认执行。

### 3.2 IDE 与 AI IDE 的区别

传统 IDE 提供代码编辑、语法提示、文件管理、构建运行和调试等工具；AI IDE 在此基础上集成大语言模型或 Agent，能够根据自然语言指令理解项目、生成和修改代码、分析错误、辅助测试及执行开发任务。

### 3.3 认识 AI IDE 工具

教程介绍了 Antigravity、Trae、Cursor、Qoder、CodeBuddy、VS Code + Cline、Kiro 等工具，并提示可以结合价格、模型选择、Agent 能力、运行速度和性能进行选择。

### 3.4 本地 AI IDE 实战

官方示例以 Trae 为工具，主要流程为：

1. 安装并了解 Trae 的基本界面。
2. 新建空项目文件夹，并使用 AI IDE 打开。
3. 在 Agent/聊天侧栏中提出需求，让 AI 使用 React 创建贪吃蛇。
4. 运行项目，观察执行过程；遇到权限确认或命令执行提示时，理解操作后再确认。
5. 对照预期检查运行效果，把错误信息或截图反馈给 AI，迭代修复。
6. 可继续让 AI 解释代码结构、核心数据和游戏逻辑。
7. 将界面优化要求拆成具体、可执行的描述，再逐步调整。

### 3.5 高效与 AI 沟通的方法

- **说清楚需求：** 说明用途、功能组成、使用限制和期望交付形式。
- **控制开发节奏：** 先完成最小可运行版本，再逐步增加功能；每次修改后运行验证。
- **善用截图和报错：** 提供当前画面、完整错误信息和复现步骤；截图分析需要模型支持图像输入。
- **建立反馈闭环：** 描述“做了什么、预期是什么、实际发生什么”，要求 AI 解释原因并提出修复方案。
- **检查与回退：** 审查 AI 产生的代码变更；效果不符合预期时，使用版本控制或 IDE 提供的回退能力恢复。

## 4. 本次实践项目：蛇潮 SURVIVORS

### 4.1 项目简介

制作一个可在浏览器运行的单机 2D 俯视角 Roguelike 割草游戏。玩家控制蛇头自由移动，蛇身自动跟随，通过自动攻击、击败敌人、收集经验和选择升级，在逐渐增强的敌潮中生存。

### 4.2 计划实现的核心玩法

- **角色：** 赤焰蛇、雷霆蛇、玄甲蛇，具有不同初始能力和属性方向。
- **蛇身：** 随蛇头移动并自动跟随；长度可成长，并参与战斗或防御机制。
- **敌人：** 史莱姆、疾行兽、骷髅战士、毒雾虫、精英怪和 Boss，设计不同移动或攻击行为。
- **武器：** 火焰弹、雷电链、旋刃、毒雾、蛇影分身。
- **成长：** 击败敌人获得经验；升级时提供随机选项，强化攻击、生存、特殊能力或武器。
- **进阶机制：** 武器进化、Combo 连杀和 Fever Time。
- **游戏流程：** 开始、角色选择、战斗、升级、Boss 挑战、结算和重新开始。

以上是项目设计目标。具体功能以实际完成并测试的代码为准，不将计划中的功能提前标记为已实现。

### 4.3 技术方案（计划）

- React + TypeScript + Vite
- HTML5 Canvas 2D 游戏渲染
- 游戏逻辑与 UI 分离
- 独立游戏循环与模块化实体管理
- Vitest（用于核心逻辑测试，实际采用情况以项目代码为准）
