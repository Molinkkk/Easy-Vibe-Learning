# 架构与实施方案

## 边界

React 负责菜单、HUD、升级、结算；Canvas 负责战场。Game 类不引用 DOM，requestAnimationFrame 传入秒制 delta time，每帧上限 50ms，后台失焦暂停。HUD 每 90ms 更新一次。画布按窗口与 DPR（上限 2）缩放，世界坐标独立，摄像机跟随玩家。

## 模块

- config.js：地图、敌人数值、经验阈值、限次升级。
- player.js：归一化输入、边界、细分路径采样与蛇身弧长插值。
- enemies.js：环形远距离生成、追踪、疾行兽周期冲刺、接触伤害。
- weapons.js：目标选择、追踪投射物、命中。
- drops.js：经验吸附、收集。
- engine.js：状态机、生成节奏、伤害/死亡/掉落、升级事务、重启。
- renderer.js：网格、蛇/敌人/火焰、伤害数字、击杀粒子。
- main.jsx / style.css：界面、输入、RAF、触控和响应式布局。

状态：menu → playing ↔ paused；playing → upgrade → playing；playing → ended。重启重建所有局内数据。

## V1 数值

2400×1800 地图，生命 100，速度 210，初始 10 节，间距 14。蛇身每 0.55 秒伤害 5+节数×0.6；玩家受击无敌 0.7 秒。火焰基础 18 伤害、0.65 秒间隔、520 范围、440 弹速。经验阈值 round(16+9L+1.1L²)。生成间隔从 0.8 秒降到最低 0.18 秒，敌人上限 160。

史莱姆：20 HP / 48 速度 / 8 伤害；疾行兽：15 / 105 / 12（周期 1.9 倍冲刺）；骷髅：42 / 65 / 16。每类具有独立掉落经验。

伤害最多 +100%，间隔最多 ×0.9⁵，生命最多 +125，速度最多 +32%，蛇身最多增加 18 节。超过全部可选升级后改为治疗。

## 分阶段门槛

V1：完成基础闭环与测试后才进入 V2。90 秒试炼用于功能验收。

V2：挑战延长 600 秒。角色配置：赤焰伤害 ×1.2、雷霆间隔 ×0.8 且链数 +1、玄甲生命 150 且承伤 ×0.8。五武器均设 1–5 级，增加独立配置表与伤害事件。进化表统一配置 fire Lv5+fireCore → inferno；lightning Lv5+energyCore → tempest；blade Lv5+windCore → void。升级属性设硬上限，暴击率最多 60%、暴伤最多 3 倍、减伤最多 60%。

精英在 120/240/420 秒出现并掉核心；Boss 在 540 秒出现，66%/33% HP 转阶段。攻击前显示 0.9 秒落点圈，随后冲击/环形弹幕。Boss 击杀优先胜利，600 秒存活胜利。Combo 断档 3 秒清零，每 10 杀倍率 +0.1（上限 2），30 连杀触发 6 秒 Fever，设置触发冷却防止持续重触发。

V3：WebAudio 交互后启用、静音设置、粒子池/空间网格、掉落合并、低端设备缩放、移动设备实测、长局数值平衡。每阶段记录文件、测试、缺口及下一步，不能将规划视作实现。
