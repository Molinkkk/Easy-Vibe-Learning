# 拾光 · 电商素材工作台

Task03 V0.1 可交互课程原型。原生 HTML、CSS、JavaScript，无构建或安装依赖。

## 本地启动

在本目录运行：

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:5173 。停止服务使用 Ctrl+C。请通过 HTTP 打开，避免 file 协议下存储差异。

## 演示流程

1. 空表单点击生成，观察必填提示。填写商品名称但不选图，观察素材提示。
2. 填写商品信息，选择 JPG / PNG / WebP（最大 2MB），观察预览；选择其他格式或过大文件会提示。可添加参考图与 http(s) 链接。
3. 点击“导入样例”模拟 Excel 批量导入两条商品；点击商品按钮可切换并修改。
4. 点击生成，观察生成中与完成状态。生成主图使用原素材，不进行 AI 绘图；文案为规则模拟。
5. 编辑标题和卖点，自动保存，也可点击保存修改；点击保留草稿，在草稿页筛选已保留。
6. 点击存为模板，填写名称和逗号分隔标签。打开模板管理，按名称或标签搜索。
7. 在草稿列表打开另一件商品，再在模板管理点击“应用到当前草稿”；验证商品属性替换、主图方案套用，再修改文案。自由编辑的文字无法保证包含可替换属性，需人工核对。
8. 勾选“演示生成失败状态”，生成后查看失败提示；再次点击重试。
9. 刷新页面检查草稿和模板保留。删除操作有二次确认。

## 数据与边界

- 数据保存在当前浏览器的 localStorage，不提供跨设备同步。图片作为 Data URL 保存，配额满时会提示仅在当前会话保留。
- 不会上传图片、访问参考链接或调用 AI API；参考素材仅供记录与预览。
- 模板会复用保存的图像，因此跨商品套用后应人工更换成目标商品的真实素材。
- 图片限制、必填列和分类是可替换的原型假设。业务收益、真实用户访谈、生成服务、平台发布及生产级 Excel 导入未实现。
- 本项目依据课程案例，不代表已完成独立访谈或证实效率提升。
