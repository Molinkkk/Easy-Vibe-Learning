# 验证记录

日期：2026-11-25。通过本地 HTTP 服务与 Codex 浏览器执行。

## 第一轮

- 页面启动：工作台表单、模拟声明、空结果、导航可见。
- 空输入：点击生成显示“请先填写商品名称”。
- 样例批量：导入两条样例、提交，草稿数量变为 2，各自显示商品名称、图片、标题及文案。
- 内容编辑：修改标题并保存，草稿页展示修改后的标题。
- 模板保存：输入模板名称“春日测试方案”与标签“春日,家居”，模板管理可查到。
- 跨商品套用：打开保温杯草稿，搜索春日模板并套用，提示已应用到保温杯，文案替换为保温杯材质、尺寸、颜色。
- 失败：勾选演示失败并提交，出现明确失败消息；再次点击可重试。

## 第二轮优化

- 批量生成后同步左侧表单与当前预览商品，减少商品错配。
- 样例切换时保留修改，图像随样例切换；托特包使用独立示意图。
- 文案编辑自动保存，保留显式保存按钮提供反馈。
- 刷新后恢复最近草稿与商品信息。
- 提交时快照商品与图片，避免等待期间修改造成结果漂移。

## 补充验收与修复

- 有效 PNG：通过浏览器文件选择器选择实际文件，预览图片完成解码，naturalWidth 为 1（测试图为 1×1 PNG）。
- 不支持格式：选择 TXT，提示“不支持的图片格式，请选择 JPG、PNG 或 WebP”。
- 大小边界：选择 2MB + 1 字节 PNG，提示“图片超过 2MB，请压缩后重试”。
- 损坏图片：选择扩展名为 PNG 的无效内容，提示“图片损坏或无法读取，请换一张图片”。
- 未选素材：从“创作新素材”进入，填写商品名后生成，显示“请先选择商品图片”。
- 移动视口：390×844 下检查工作台、草稿页、模板页，页面 clientWidth 与 scrollWidth 均为 375，无水平溢出。已重置测试视口。
- 新建入口：现在明确清空商品、图片与选中草稿，避免把旧草稿当成新商品。
- 异步导航：模拟失败生成期间切换到模板页，完成后仍留在模板页，未被错误重绘为工作台。
- 其他修复：参考图随草稿恢复；生成时一起快照参考图；批量验证所有商品名称；模板文本替换只处理商品名称、品牌、材质、尺寸和颜色；长文本与窄屏文件输入增加约束。

上述验证覆盖指定异常分支；全部浏览器组合、存储配额耗尽仍未逐一实测，不视为全面兼容认证。


## 最终补充验证

- JPEG 与 WebP：使用实际 80×60 图片通过文件选择器上传；预览分别为 image/jpeg 与 image/webp Data URL，naturalWidth=80、naturalHeight=60。
- 批量编辑：将第一条样例改名为“批量编辑验证杯”，切换第二条再返回，名称仍保留；生成后在草稿页按该名称可找到对应标题和文案。
- 生成成功期间导航：提交批量生成后立即切换模板管理，完成后页面仍是模板管理，草稿数从 5 增至 7。
- 浏览器错误日志：本轮测试未捕获 error 级日志。
- JavaScript 语法检查通过。保留跨浏览器与存储配额测试为后续事项。
